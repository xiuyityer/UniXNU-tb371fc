# V135 公开验证摘要

最后更新：2026-11-09。V129 内容以下作为历史基线保留。

这些结果来自原移植工作区的实机测试和用户回报；不是从此公开仓库独立构建的结果。公开仓库没有设备专属原始日志、分区身份、备份或可重放的刷写命令。

## 实机结果

- V120：用户确认进入 iPadOS 桌面。
- V128：用户确认桌面可滑动、GPU 工作。匹配的原生日志记录 5323 次有效触摸读取和 4784 次 HID 上报，错误均为零；八核活动、GPU 提交/完成及持久 Data 的 89613 次写入均有记录，Data 错误为零。
- 电源键：用户确认能息屏和亮屏；音量键仍未正常工作。长时间睡眠与完整电源管理不在此结论内。
- V129：用户反馈滑动较 V128 提高约 5–10 FPS，并决定暂停 GPU 优化。帧率来自左上角工具的观察，未形成统一条件的帧时间基准；V129 精确运行日志尚未回读。
- V135：用户确认完整应用可打开、Settings About 正常、触摸与 GPU 正常。壁纸仍黑；用户决定暂停平板调试并返回原系统，当前模式未知。
- V136 触摸/GPU 回归后已退回 V135。V137/V138 壁纸尝试未解决黑屏，不应作为稳定基线。
- 电池与充电、音量键仍未解决；网络和音频没有实机通过结论。

## 当前可复核内容

```sh
python3 scripts/check_repository.py
python3 scripts/check_catalog.py
```

第二项需要 Python 3.11+ 和网络，下载固定提交、固定 SHA-256 的官方记录校验器及组件表，检查本仓库的 board/porting TOML 和证据路径。两项均不编译系统、不连接设备。源码检查通过不代表完整系统或全部功能通过。
